\chapter{SOURCE CODE}
Lampirkan kode lengkap atau skrip yang tidak muat atau tidak relevan untuk ditampilkan di bab pembahasan. Kode di sini tidak harus diberi penjelasan detail; cukup caption singkat yang menyebutkan apa fungsinya.

\begin{lstlisting}[language=SQL, caption={Skrip lengkap pembuatan tabel}]
CREATE TABLE contoh (
    id    INT AUTO_INCREMENT PRIMARY KEY,
    nama  VARCHAR(100) NOT NULL,
    dibuat DATETIME DEFAULT NOW()
);
\end{lstlisting}
